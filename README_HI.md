## ये है क्या

Vesper Movies एक ऐसा ऐप है जो एक साथ कई सोर्स से सर्च करता है, चलने लायक स्ट्रीम निकालता है, और
उसे अपने ही बिल्ट-इन प्लेयर में चला देता है — फाइल में जितने भी ऑडियो, वीडियो और सबटाइटल ट्रैक हैं,
सब दिखते हैं और बीच में ही बदले जा सकते हैं।

एक ही कोड से यह Windows, Linux, Android फोन और टैबलेट, और Android TV, Fire TV तथा Google TV पर
चलता है। जो डिवाइस हाथ में है, इंटरफेस उसी के हिसाब से बदल जाता है: टच पर नीचे डॉक, और माउस या
रिमोट पर बाईं तरफ रेल।

## खास बातें

**डिस्कवर।** ऊपर एक बड़ा स्पॉटलाइट और नीचे कतारें — अभी जो देखने लायक है, सब। जब TMDB की key लगी हो
तो वहां से, वरना Cinemeta से, ताकि बिना किसी सेटअप के भी ऐप पहले दिन से काम करे।

**सारे सोर्स पर एक साथ सर्च।** एक बार टाइप कीजिए और हर चालू सोर्स पर एक साथ सर्च चला जाता है। जो
सोर्स नहीं पहुंच रहा वो बस हल्का पड़ जाता है, पूरा एरर पेज नहीं आता, और बाकी के रिजल्ट तुरंत दिख
जाते हैं।

**प्लेबैक ऐप के अंदर ही।** स्ट्रीम libmpv से ऐप के अंदर चलती है। हर ऑडियो ट्रैक, वीडियो ट्रैक और
सबटाइटल ट्रैक लिस्ट में आता है और चलते-चलते बदला जा सकता है — वो सबटाइटल फाइलें भी जो सोर्स अलग से
देता है।

**सबटाइटल सेटिंग, सिर्फ on/off नहीं।** साइज, रंग, आउटलाइन, पीछे का बॉक्स, ऊपर-नीचे की जगह और टाइमिंग
— सब लाइव बदलता है और अगली बार के लिए याद भी रहता है।

**जहां छोड़ा था वहीं से।** देखते-देखते पोजीशन सेव होती रहती है, तो अधूरी छोड़ी हुई फिल्म होम स्क्रीन
पर उसी जगह से इंतजार करती मिलती है।

**माय लिस्ट।** किसी भी टाइटल को स्टार कीजिए, उसकी अपनी कतार और अपना पेज बन जाता है।

**डाउनलोड।** एक एपिसोड या पूरा सीजन ऑफलाइन के लिए सेव कीजिए — रोकना और दोबारा शुरू करना दोनों चलता
है, ऐप बंद करके खोलने पर भी।

**लाइव टीवी।** कोई भी M3U प्लेलिस्ट URL डालिए और कैटेगरी के हिसाब से लाइव चैनल देखिए।

**रिमोट के लिए बना हुआ।** हर स्क्रीन D-pad से चलती है। फोकस हमेशा साफ दिखता है, हर कतार याद रखती है
कि आप कहां छोड़कर गए थे, और कहीं भी माउस या टचस्क्रीन की जरूरत नहीं पड़ती।

## इंस्टॉल कैसे करें

अपने डिवाइस के हिसाब से फाइल [latest release](https://github.com/AroseEditor/Vesper-Movies/releases/latest) से डाउनलोड कीजिए।

**Windows** — `vesper-movies-windows-x64.zip` लीजिए, कहीं भी अनजिप कीजिए और `vesper_movies.exe`
चलाइए। और कुछ इंस्टॉल करने की जरूरत नहीं, प्लेयर अंदर ही आता है।

**Linux** — `vesper-movies-linux-x64.tar.gz` लीजिए:

```bash
tar -xzf vesper-movies-linux-x64.tar.gz
./vesper_movies
```

अगर `libmpv` पहले से नहीं है तो अपने डिस्ट्रो से लगा लीजिए:

```bash
sudo apt install libmpv2 mpv        # Debian, Ubuntu
sudo pacman -S mpv                  # Arch
```

**Android फोन या टैबलेट** — 2017 के बाद के किसी भी फोन के लिए `vesper-movies-arm64-v8a.apk`, और
पुराने 32-बिट फोन के लिए `vesper-movies-armeabi-v7a.apk`। पूछे तो unknown sources से इंस्टॉल की
इजाजत दे दीजिए।

**Android TV, Fire TV और Google TV** — वही `vesper-movies-arm64-v8a.apk` फाइल। Downloader ऐप से या
ADB से साइडलोड कीजिए:

```bash
adb connect <device-ip>:5555
adb install vesper-movies-arm64-v8a.apk
```

इसके बाद Vesper टीवी के लॉन्चर में अपने बैनर के साथ दिखने लगेगा, और पूरा इंटरफेस रिमोट के लिए ही
बना हुआ है।

## सोर्स से बनाएं

Flutter SDK 3.47 या उससे नया चाहिए।

```bash
git clone https://github.com/AroseEditor/Vesper-Movies.git
cd Vesper-Movies
flutter pub get
flutter run -d windows        # या linux, या जुड़ा हुआ android डिवाइस
```

रिलीज बिल्ड:

```bash
flutter build apk --release --split-per-abi
flutter build windows --release
flutter build linux --release
```

Windows पर `flutter run` चलाने के लिए Developer Mode चालू होना चाहिए, वरना बिल्ड symlink नहीं बना
पाता। एक बार `start ms-settings:developers` चलाकर इसे ऑन कर लीजिए।

## कॉन्फिगरेशन

पोस्टर और कैटलॉग डिफॉल्ट रूप से Cinemeta से आते हैं — न कोई key चाहिए, न अकाउंट।

बेहतर आर्टवर्क के लिए — सही बैकड्रॉप, टाइटल लोगो, ज्यादा साफ पोस्टर — बिल्ड करते समय
[TMDB](https://www.themoviedb.org/settings/api) की मुफ्त API key दे दीजिए:

```bash
flutter build apk --release --dart-define=TMDB_API_KEY=your_key_here
```

key देना जरूरी नहीं है और ऐप कभी चलते-चलते key नहीं मांगता। ध्यान रहे कि रिलीज बिल्ड में डाली गई key
उस फाइल से निकाली जा सकती है, इसलिए वही key इस्तेमाल कीजिए जिसके खुलने से फर्क न पड़े; TMDB की v3 key
सिर्फ पढ़ने के लिए होती है और हर key की अपनी लिमिट होती है।

## प्राइवेसी

Vesper में कोई telemetry नहीं, कोई analytics नहीं, कोई crash reporting नहीं। इस प्रोजेक्ट का अपना
कोई सर्वर है ही नहीं। आपकी हिस्ट्री, लिस्ट और सेटिंग्स आपके ही डिवाइस पर फाइलों में रहती हैं और कहीं
नहीं भेजी जातीं।

लॉग फाइल में न IP लिखा जाता है, न आपका सर्च, न प्लेलिस्ट का URL, न पूरा रिक्वेस्ट URL। रिक्वेस्ट सिर्फ
scheme और host तक लिखी जाती है, और फाइल पाथ होम फोल्डर के हिसाब से लिखे जाते हैं ताकि आपका यूजरनेम
डिस्क पर न पहुंचे।

जो बात ऐप छिपा नहीं सकता वो ये है कि स्ट्रीमिंग के लिए उन सर्वरों से बात करनी ही पड़ती है जिन पर
कंटेंट रखा है। उन्हें आपका IP वैसे ही दिखता है जैसे किसी भी ब्राउज़र में दिखता। दो सोर्स अपने डिजाइन
की वजह से लोकल नेटवर्क पर सादे HTTP से बात करते हैं, और उनकी इजाजत सिर्फ उन्हीं के अपने पतों तक सीमित
रखी गई है, पूरे ऐप के लिए नहीं।
